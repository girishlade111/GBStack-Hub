# **App Name**: GBStack Hub

## Core Features:

- Homepage Introduction: A visually engaging introduction highlighting Girish Lade's skills, experience, and mission.
- Projects Showcase: Dedicated section showcasing GBStack, the AI Website Builder, and the Multi-LLM AI Agent with descriptions and links to live demos or GitHub repositories, listing the projects available from the user's GitHub account (https://github.com/girishlade111).
- Skills Overview: Clearly list technical skills in web development (HTML, CSS, JavaScript, Tailwind, React), AI (OpenRouter, Gemini, DeepSeek), and design.
- AI Tool Suggestion Tool: AI-powered tool that analyzes current trends in tech, crypto and AI (using live data, refreshed daily), and suggests potentially profitable niches for new AI tools that Girish can build. The tool will be provided an action to retrieve top news stories (tool).
- Social Media Integration: Links to Instagram (https://www.instagram.com/girish_lade_/), LinkedIn (https://www.linkedin.com/in/girish-lade-075bba201/), GitHub (https://github.com/girishlade111), and CodePen (https://codepen.io/Girish-Lade-the-looper).
- Contact Form: A simple form for visitors to send messages directly to girishlade111@gmail.com.
- GBStack Branding: Consistent use of GBStack branding, logo, and color scheme throughout the website.

## Style Guidelines:

- Primary color: Deep Blue (#293B5F) to convey professionalism and innovation.
- Background color: Light Gray (#F0F0F0) to provide a clean and modern backdrop.
- Accent color: Teal (#3D84A8) to highlight key elements and CTAs, offering a vibrant contrast.
- Body font: 'PT Sans', a humanist sans-serif, for readability and a touch of warmth. Headline font: 'Space Grotesk', a proportional sans-serif with a computerized, techy, scientific feel, will be used for a bold contemporary statement.
- Use a set of simple, modern icons to represent skills, tools, and technologies.
- Employ a clean, grid-based layout with ample white space to ensure a user-friendly and visually appealing experience.
- Subtle animations and transitions to enhance user engagement without being distracting.
